# Radar System Notebooks

**Practical, runnable Jupyter notebooks for radar signal processing and system prototyping.**  
This repository collects focused notebooks, example data, and helper scripts to explore radar signal generation, preprocessing, feature extraction, and basic detection/visualization workflows.

---

## Overview

This repo is intended for engineers, researchers, and students who want hands‑on examples to learn radar concepts and reproduce experiments quickly. Notebooks are kept modular so you can run individual steps (data generation, preprocessing, feature extraction, modeling) or the full pipeline end to end.

**Key goals**
- Provide clear, runnable examples for radar data workflows  
- Demonstrate preprocessing and feature engineering techniques commonly used in radar systems  
- Offer simple detection and visualization demos that are easy to adapt to real data
